# LuxeGlow Salon - Premium Beauty & Wellness

LuxeGlow is a modern, high-end web application built for a luxury salon and spa. It features a stunning client-facing website for booking services, exploring treatments, and viewing team members, alongside a comprehensive admin dashboard for managing appointments, revenue, and clients.

## 🚀 Tech Stack

This project is built using modern web technologies to ensure a fast, scalable, and secure application with premium aesthetics:

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **UI Components:** [Radix UI](https://www.radix-ui.com/) & [Lucide React](https://lucide.dev/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Charts (Admin):** [Recharts](https://recharts.org/)
- **Theming:** [next-themes](https://github.com/pacocoursey/next-themes) for seamless dark/light mode transitions

## ✨ Features

- **Luxury User Interface:** A visually stunning, responsive design with smooth animations and a premium dark-mode aesthetic (Midnight, Gold, Blush, Lavender).
- **Service & Team Showcase:** Beautifully presented services, spa treatments, and team member profiles.
- **Admin Dashboard:** Comprehensive metrics, interactive revenue charts, service popularity statistics, and recent booking management.
- **Responsive Design:** Flawless experience across desktop, tablet, and mobile devices.

## 🛠️ Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/luxeglow.git
   cd luxeglow
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open the application:**
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. The Admin dashboard can be accessed at `/admin`.

## 📁 Project Structure

- `/app`: Next.js App Router pages and layouts (including `/admin`, `/booking`, `/services`, etc.).
- `/components`: Reusable UI components organized by feature (home, admin, shared).
- `/lib`: Utility functions and mock data for the application.
- `/public`: Static assets like images and icons.
